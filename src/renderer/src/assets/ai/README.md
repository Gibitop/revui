# AI provider logos

Unmodified provider and model-family SVGs (Codex, OpenCode, OpenAI, Claude, Gemini, DeepSeek, Qwen, Mistral, Grok, Meta, Kimi, Cohere, Perplexity, and NVIDIA) from [SVGL](https://github.com/pheralb/svgl/tree/ed75393dbe6eba6e446e208abb6826ecd1abd36d/static/library), pinned to revision `ed75393dbe6eba6e446e208abb6826ecd1abd36d`.

The upstream repository license is included in `LICENSE.txt`. Brand marks belong to their respective owners. Keep these assets unchanged; source updates from SVGL instead of drawing replacements.

Additional families absent from SVGL use the attributed assets in [lobe/README.md](lobe/README.md). Unknown models retain the neutral fallback, including unidentified stealth models.
